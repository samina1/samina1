##  Selected AI, ML, DL & RL Research Projects

###  Reinforcement Learning & Personalized Learning

**1. Q-Learning for Personalized Learning Strategies**
- Developed an AI-based Q-learning approach to support personalized learning strategies for students with disabilities.
- **Focus:** Reinforcement Learning, Q-Learning, Personalized Education.
- **Publication:** [STEM Education (2026)](https://scholar.google.com/scholar?q=AI-based+Q-learning+model+for+personalized+learning+strategies+for+students+with+disabilities)

**2. Reinforcement Learning for Adaptive E-Learning**
- Designed a smart e-learning framework using reinforcement learning for personalized adaptive learning and sequential learning-path recommendations.
- **Focus:** RL, Adaptive Learning, Intelligent Recommendation Systems.
- **Publication:** [IEEE Access (2023)](https://doi.org/10.1109/ACCESS.2023.3305584)

**3. Personalized Top-N Course Recommendation System**
- Developed a personalized framework for recommending relevant online courses based on learner preferences and learning needs.
- **Focus:** Recommendation Systems, Machine Learning, Personalized Learning.
- **Publication:** [Scientific Reports (2024)](https://doi.org/10.1038/s41598-024-56497-1)

**4. IoT-Enabled E-Learning and MOOC Recommendation**
- Developed a personalized e-learning and MOOC recommendation system for smart education environments.
- **Focus:** Recommender Systems, Machine Learning, Smart Education.
- **Publication:** [IEEE Access (2023)](https://doi.org/10.1109/ACCESS.2023.3336676)

###  Machine Learning & Explainable AI

**5. Breast Cancer Prediction Using Ensemble Learning**
- Investigated ensemble machine learning and multi-model features to improve breast cancer detection and classification.
- **Focus:** Classification, Ensemble Learning, Medical AI.
- **Publication:** [Life (2023)](https://doi.org/10.3390/life13102093)

**6. Breast Cancer Prediction with Deep Neural Networks**
- Developed a breast cancer prediction approach integrating deep neural networks with ensemble models.
- **Focus:** Deep Learning, Ensemble Models, Clinical Prediction.
- **Publication:** [Chemometrics and Intelligent Laboratory Systems (2025)](https://doi.org/10.1016/j.chemolab.2025.105399)

**7. Diabetes Prediction Using Ensemble Deep Learning**
- Developed an ensemble deep learning-based clinical decision support system for diabetes prediction.
- **Focus:** Deep Learning, Ensemble Learning, Healthcare AI.
- **Publication:** [IEEE Access (2024)](https://doi.org/10.1109/ACCESS.2024.3436641)

**8. Heart Disease Prediction Using Hybrid Deep Neural Networks**
- Investigated hybrid deep neural network architectures for heart disease prediction.
- **Focus:** Neural Networks, Predictive Analytics, Healthcare AI.
- **Publication:** [IEEE Access (2023)](https://doi.org/10.1109/ACCESS.2023.3328909)

###  Deep Learning & Computer Vision

**9. Brain Tumor Detection and Segmentation**
- Developed a brain tumor detection and segmentation approach using densely connected convolutional networks and stacking ensemble learning.
- **Focus:** CNNs, Medical Image Analysis, Image Segmentation.
- **Publication:** [Computers in Biology and Medicine (2025)](https://doi.org/10.1016/j.compbiomed.2025.109703)

**10. COVID-19 Detection from Chest X-Rays**
- Applied convolutional neural networks and transfer learning to classify COVID-19-related chest X-ray images.
- **Focus:** CNNs, Transfer Learning, Medical Imaging.
- **Publication:** [Scientific Programming (2022)](https://doi.org/10.1155/2022/5145614)

###  NLP, LSTM & AI-Based Health Surveillance

**11. Disease Surveillance Using Social Media**
- Applied machine learning, deep learning, recurrent neural networks, and word embeddings to identify disease-related information and monitor public health trends from social media.
- **Focus:** NLP, RNNs, LSTMs, Text Classification, Health Informatics.
- **Selected Publications:**
  - [Dengue/Flu Detection Using LSTM and Word Embeddings (2020)](https://doi.org/10.1109/ACCESS.2020.3031174)
  - [Dengue Disease Detection Using RNNs and TF-IDF (2020)](https://doi.org/10.1109/ACCESS.2020.3009058)
  - [COVID-19 Public Discourse Classification Using RNNs (2022)](https://doi.org/10.1007/s00500-022-07405-0)
  - [Seasonal Outbreak Detection Using Twitter Data (2021)](https://doi.org/10.1155/2021/5520366)
